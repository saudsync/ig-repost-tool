Repost Review Queue

This page reads data/drafts.json. Since GitHub Pages is static, clicking Approve here updates the display only — it does NOT write back to the repo. To actually mark a draft approved and publish it, edit data/drafts.json (set status to "approved") and run scripts/publish_post.py --shortcode <code>, or wire this button up to a small backend / GitHub API call if you want one-click approval.
